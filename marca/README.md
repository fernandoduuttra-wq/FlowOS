# Marca

Esta pasta recebe a identidade visual do negócio.

Quando `design.json` existir, ele será a fonte de verdade para cores, fontes, formas, escala e espaçamento. Logos, fontes e imagens de referência também ficam aqui.

Se a identidade ainda não estiver definida, use a skill `identidade`. Não improvise tokens visuais diferentes em cada peça.
